## 방침을 웹에 올리기

앱스토어는 제출 폼에 **개인정보 처리방침 주소를 반드시** 요구한다. 없으면 제출 자체가
안 된다. 구글 OAuth 동의 화면에도 같은 주소를 넣는다(그쪽은 선택이다).

가장 가벼운 길은 이 저장소의 GitHub Pages 다.

1. GitHub → 저장소 → Settings → Pages
2. Source 를 `Deploy from a branch`, Branch 를 `main`, 폴더를 `/docs` 로 둔다
3. 몇 분 뒤 `https://<계정>.github.io/steelers-app/privacy` 로 열린다

저장소가 비공개면 Pages 가 안 되므로 공개로 바꾸거나 다른 곳에 올린다.

## 고칠 때

**코드가 바뀌면 이 글도 바뀐다.** 특히 아래를 건드렸으면 둘 다 본다.

- 새로 저장하는 항목이 생겼다 → privacy.md 의 "받는 정보", app-store.md 의 App Privacy
- 분석·광고 도구를 넣었다 → 두 문서의 "받지 않는 것" 과 Tracking 답이 거짓이 된다
- 신고·차단 흐름을 바꿨다 → 심사 메모의 설명이 실제와 달라진다
- 앱 안 고지 문구(MyScreen)를 바꿨다 → 앱스토어 설명과 표현을 맞춘다
