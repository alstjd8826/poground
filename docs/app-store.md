## 연령 등급

애플이 2025-07 에 등급 체계를 바꿨다(4+·9+·13+·16+·18+, 질문지 개편). 질문지에는 **사용자 생성 콘텐츠**를 묻는
항목이 있고, 그 답에 따라 등급이 올라간다. App Store Connect 가 답으로 등급을 정하므로 여기서는 답만 정해 둔다.

- 사용자 생성 콘텐츠(이용자가 글·사진·댓글을 만들어 다른 이용자와 나눈다) → **예**
  - 근거로 적을 것: 약관 동의, 신고·차단, 운영자 신고함에서 24시간 이내 삭제
- 광고 → **아니오**
- 무제한 웹 접근 → **아니오** (소식 원문 페이지만 앱 안 브라우저로 연다)
- 폭력·성적 내용·도박·약물 등 나머지 → **없음**

나온 등급을 여기에 적는다: `(제출 때 기록)`. 개인정보 처리방침은 만 14세 미만의 개인정보를 받지 않는다(5장). 그와
어긋나지 않게, 등급이 그보다 낮게 나오면 "더 높은 등급으로 설정" 을 쓴다.

## App Privacy (데이터 수집 질문지)

앱이 실제로 무엇을 저장하는지에 맞춘 답이다. **코드가 바뀌면 여기도 고친다.**

### 수집한다고 답할 것

| 애플 분류    | 항목               | 용도              | 신원 연결 | 추적   |
| ------------ | ------------------ | ----------------- | --------- | ------ |
| Contact Info | Email Address      | App Functionality | 예        | 아니오 |
| Contact Info | Name               | App Functionality | 예        | 아니오 |
| User Content | Photos or Videos   | App Functionality | 예        | 아니오 |
| User Content | Other User Content | App Functionality | 예        | 아니오 |
| Identifiers  | User ID            | App Functionality | 예        | 아니오 |

- **Email Address** — 카카오·구글이 넘겨주는 계정 메일. 계정 구분과 같은 사람의 로그인 잇기에만 쓴다
- **Name** — 소셜 프로필 이름(닉네임 기본값)과 이용자가 정한 닉네임·아이디
- **Photos or Videos** — 게시글 사진(전체 공개면 다른 이용자에게 보인다), 팬카드 사진, 직접 넣은 선수 사진, 프로필
  이미지
- **Other User Content** — 게시글 본문, 댓글, 신고 사유, 직관 기록(다녀온 경기)
- **User ID** — 계정 식별자

### 수집하지 않는다고 답할 것

- Usage Data (Product Interaction 등) — 분석 도구를 넣지 않았다
- Diagnostics (Crash Data 등) — 수집 도구를 넣지 않았다
- Location — 받지 않는다
- Identifiers → Device ID / 광고 식별자 — 받지 않는다
- Financial Info, Health, Contacts, Search History, Browsing History, Sensitive Info — 없다

### Tracking

**"No"** 로 답한다. 다른 회사의 앱·웹사이트에서 얻은 자료와 묶지 않고, 데이터 브로커에 넘기지 않으며, 광고
식별자를 쓰지 않는다. 따라서 App Tracking Transparency 창을 띄우지 않는다.
